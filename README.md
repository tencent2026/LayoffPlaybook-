**腾讯裁员宝典**

虽然以“腾讯”命名，但它的适用对象并不局限于腾讯员工。项目面向所有互联网从业者，覆盖大厂、中小厂、外包团队、创业公司及各类科技公司。裁员逻辑、组织调整信号、权益维护方法、谈判策略和求职重启路径，在不同互联网公司之间往往高度相似，因此本项目对其他互联网公司同样有效。
项目希望帮助开发者、产品、运营、测试、设计、数据、算法、市场、销售等岗位同学，提前识别职场风险，建立个人防御机制，并在遭遇裁员、降薪、调岗、边缘化或合同变更时，能够更冷静、更有序、更有底气地维护自身权益。
我们并不鼓励制造焦虑，也不主张盲目对抗。但面对资本逐利、组织收缩和不确定性增加的现实，个体不应独自承担所有风险。互联网从业者需要彼此分享经验、互通信息、提供建议、互相推荐机会，在合法合规的前提下抱团取暖，减少信息差，增强议价能力，共同对抗不合理的裁员安排和资本对劳动者权益的侵蚀。

### 项目主要包含

- **风险预警清单**：整理招聘冻结、预算收缩、组织调整、PIP、边缘化、合同主体变更等常见前兆，帮助尽早识别风险。
- **法律与权益指南**：梳理劳动合同、补偿计算、离职协议、社保公积金、离职证明等关键注意点，提醒谨慎签字、保留证据。
- **谈判话术模板**：提供与 HR、直属上级沟通时的表达参考，帮助争取合理补偿和缓冲时间。
- **应急行动手册**：覆盖被通知裁员后的 24 小时、72 小时和 30 天行动清单，包括财务评估、简历更新、人脉触达、求职节奏。
- **职业资产备份指南**：指导如何合规保存绩效记录、项目成果、技术贡献、推荐信和联系人信息，避免离职后信息丢失。
- **求职与转型资源**：汇总简历优化、作品集展示、面试准备、技能升级、副业探索等实用方向。
- **高风险团队**: 风险团队,部分喜欢PUA的团队, 低业绩项目

### 适合谁用

- 正在互联网/科技公司工作，担心组织调整或裁员风险的人；
- 已经收到裁员通知，需要快速知道下一步该做什么的人；
- 希望建立“反脆弱”职业体系，减少被动失业冲击的人；
- 愿意一起补充经验、模板、案例和地区性法律信息的社区贡献者。

### 使用说明

本项目内容仅供学习、交流和风险参考，不构成法律、税务或职业建议。不同地区、公司和劳动合同情况差异较大，遇到具体纠纷或补偿问题时，建议咨询专业律师或当地劳动仲裁机构。

如果你愿意参与共建，可以提交 Issue、补充模板、完善检查清单，或分享自己的匿名经验。希望这本“宝典”永远只是备用品，但一旦需要，它能帮你少一点慌乱，多一点主动权。
